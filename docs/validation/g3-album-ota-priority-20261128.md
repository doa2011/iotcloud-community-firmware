# 2026-11-28 相册提速与 OTA 抢占候选
基于 ec90540（PR CI 46123332260，25/25），新增原生相册 4096B 二进制批次（24B <IIIHHII> id,total,crc,width,height,offset,album_epoch）。仍用固定521B UART 邮箱，每块512B并核对 ACK/CRC/offset/session。HTTP 单任务在批次间可接收 OTA，不能声称在任意 TCP 字节处抢占；旧单请求路由保留兼容，HA 新原生路径需配套。HTTP ESP32 本地升级、MCU 固件上传、线上 install 与 MCU start/install 命令先请求 owner 清除已确认原生图层、取消已知属于批次的缓存、等待 UART TX 完成，更新 generation 阻止原相册恢复。只读 ota.check 不因 JPEG lock 拒绝。保留原签名/MD5/租约/Guard 验证，原命令仍完整验证；若 syntactically 合法但目标无效，可能先停止相册。非 HTTP（MQTT/串口/LAN）升级入口的异步优先调度尚待接入，旧整图请求仍可能阻塞 HTTP；不宣称全路径抢占通过。高波特率仍采用已有双端协商，禁止 handoff 时改速，OTA 沿用已协商速率，重启回落沿用原 Guard；230400/460800/921600 的实机稳定性与 OTA 交叉验证未做。需验证超时/会话变更、断流缓存、HA 代际停止、并发、各速率性能，不能把宿主测试视为实机验收。
